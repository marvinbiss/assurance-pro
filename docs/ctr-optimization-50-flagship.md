# CTR Optimization — 50 Pages Flagship

## Méthode

**Power words + Year + Specificity + Brackets + Numbers.**

Best practice CTR SERP:

- Year explicit ("2026") = +14% CTR avg
- Number specifique ("950€/an") = +25% vs vague
- Brackets/parenthèses ("[Guide]", "(2026)") = +8%
- Power words ("Économisez", "Garanti", "Comparatif") = +20%
- Title <= 60 chars (tronqué Google sinon)
- Meta description 150-160 chars = +18% CTR

## A/B Testing setup

Pour tester variants:

1. **Vercel Edge Config** : feature flag titles/metas par cohorte
2. **GSC monitoring** : tracker CTR mensuel par URL
3. **Mesurer 30 jours minimum** avant conclusion (variance saisonnière)
4. **Garder la variante avec CTR > +15%**
