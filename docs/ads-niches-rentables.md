# 30 Micro-Niches Google Ads Rentables — Vivos Assurance

Stratégie : long-tail ultra-spécifique = CPC bas + intent transactionnelle haute + landing existante (pSEO).

Méthode ROAS estimé :

```
ROAS = (Trafic × Conversion landing × Closing × Commission) / Coût total ads
Cible: ROAS > 2.5x pour valider scale
```

Hypothèses moyennes :

- Conversion landing pSEO Vivos : 8-12% (UX premium + intent matching)
- Closing devis → contrat : 25-35% (post-ORIAS)
- Commission moyenne décennale : 600€ | RC Pro : 400€ | Mutuelle TNS : 800€/an récurrent

## Settings recommandés Google Ads

### Match types

- **Phrase match** par défaut (équilibre couverture/contrôle)
- **Exact match** pour TIER 1 (max ROAS, scale après validation)
- **Broad match** uniquement avec audience signal + responsive search ads + smart bidding maxConv

### Negative keywords (à exclure absolument)

```
gratuit
emploi
mutuelle santé particulier
assurance habitation
assurance voiture
auto particulier
ancien
fr.wikipedia
définition
```

### Géolocalisation

- **TIER 1 villes** : Paris IDF, Lyon, Marseille, Bordeaux, Lille, Toulouse, Nantes, Strasbourg, Nice, Rennes
- **TIER 2** : ville par ville selon vol recherche
- **National** uniquement après validation ROAS local

### Bidding strategy

- **Manual CPC** au démarrage (max contrôle)
- Passer **Target ROAS 250%** après 30 conversions
- Smart bidding interdit avant 30 conversions/campaign

### Landing experience

- 1 landing dédiée par cluster (métier × statut × ville si volume)
- Pixel Meta + Google Tag installés
- Form submission = trigger conversion event `ads_conversion` (`devis_submitted`)
- Pre-ORIAS : substitute `preinscription_warm_lead`

### Budget allocation initial

Scale à 8-15k€/mois quand TIER 1 ROAS confirmé > 3x sur 60 jours.

## Tracking par campagne (à setup GTM)

Chaque ad doit utiliser URL avec UTM :

```
?utm_source=google
&utm_medium=cpc
&utm_campaign=decennale-plombier-ae-paris
&utm_term={keyword}
&utm_content={creative_id}
```

Le système Vivos `captureFirstTouch()` (src/lib/cro/ads-tracking.ts) persiste ces UTM en cookie 30j et attribue chaque conversion (preinscription / devis / contrat) à la campagne d'origine.

Dashboard ROAS dans `/admin/ads-roas` (à build phase 2).

## Métriques à monitorer

| Métrique                | Cible            | Action si raté                          |
| ----------------------- | ---------------- | --------------------------------------- |
| **CTR ad**              | > 3%             | Refactor copy + extension headlines     |
| **Quality Score**       | > 7/10           | Améliorer landing speed + match keyword |
| **Conversion landing**  | > 8%             | A/B test hero + form simplifié          |
| **Cost/Conversion**     | < 30% commission | Pause ou bid down                       |
| **ROAS**                | > 2.5x après 30j | Kill si < 1.5x après 60j                |
| **CPL (cost per lead)** | < 60€            | Pause si > 120€ sur 7j                  |
